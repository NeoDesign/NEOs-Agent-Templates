# Complete Python Development Team

This example composes the six core roles with the Python profile.

## Team

1. CEO / Orchestrator
2. Product Owner
3. CTO with Python Development Profile
4. Lead Developer with Python Development Profile
5. Code Reviewer with Python Development Profile
6. QA Engineer with Python Development Profile

Optional extensions:

- Run the Repository Cartographer before planning work in an unfamiliar codebase.
- Add the Documentation Specialist for public APIs, setup, operations, or releases.
- Add the Privacy Officer when personal data, telemetry, profiling, external models, or sensitive logs are involved.

## Example workflow

1. The CEO records the human objective and delegates product framing.
2. The Product Owner produces scope, non-goals, and acceptance criteria.
3. The CTO inspects repository evidence, applies the Python profile, and creates the technical plan.
4. The Lead Developer implements a focused change and supplies test evidence.
5. The Code Reviewer independently evaluates the exact revision.
6. The Lead Developer resolves required findings.
7. QA verifies acceptance criteria and regression risk.
8. Optional specialist gates report.
9. The CEO summarizes evidence and requests human authorization for merge, publication, or deployment when needed.
