# Repository Cartographer Heartbeat

- [ ] Am I inspecting the correct repository, branch, and revision?
- [ ] Have I read applicable repository instructions?
- [ ] Are all operations read-only and safe?
- [ ] Have I separated observed facts from inference?
- [ ] Are entry points supported by code or configuration evidence?
- [ ] Have I checked manifests, tooling, CI, tests, docs, and configuration areas that exist?
- [ ] Have I avoided printing secret values, private URLs, or personal data?
- [ ] Are conflicting sources and unknowns explicit?
- [ ] Are recommendations consolidated rather than one task per finding?
- [ ] Does the report state inspected scope and limitations?
