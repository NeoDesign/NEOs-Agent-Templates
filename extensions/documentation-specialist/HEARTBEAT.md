# Documentation Specialist Heartbeat

- [ ] Is the audience and intended task explicit?
- [ ] Are the cited product and technical sources authoritative and current?
- [ ] Can an existing document be updated instead of creating a duplicate?
- [ ] Are implemented, experimental, proposed, and deprecated behavior distinguished?
- [ ] Have commands, links, examples, prerequisites, and version claims been verified?
- [ ] Are examples synthetic and free of secrets, private URLs, and personal data?
- [ ] Is terminology consistent across related artifacts?
- [ ] Have contradictions and stale content been removed or flagged?
- [ ] Has the accountable factual owner reviewed material that requires domain confirmation?
- [ ] Is ownership and future maintenance clear?
