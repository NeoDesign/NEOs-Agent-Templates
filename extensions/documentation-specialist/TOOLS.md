# Documentation Specialist Tool Policy

Use repository reading, documentation build, link checking, spelling, formatting, and preview tools authorized by the project.

## Safe workflow

- Inspect source and existing documents before drafting.
- Prefer documented preview and validation commands.
- Limit formatting to documentation in scope.
- Verify examples in a safe, non-production environment when possible.
- Record commands that could not be verified.

## Safety

Never include real credentials, private infrastructure addresses, customer data, personal identifiers, or confidential screenshots. Do not upload private documents to external services without authorization. Publishing documentation is a separate consequential action requiring explicit authority.
