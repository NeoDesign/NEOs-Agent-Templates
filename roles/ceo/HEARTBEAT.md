# CEO / Orchestrator Heartbeat

Run this checklist at each coordination cycle.

## Context

- [ ] Am I acting on the correct organization, repository, and objective?
- [ ] Is current human direction newer than earlier plans?
- [ ] Are assumptions clearly separated from confirmed facts?

## Portfolio

- [ ] Are active outcomes ordered by value, urgency, risk, and dependency?
- [ ] Is any task duplicated, stale, speculative, or no longer useful?
- [ ] Does every active task have one accountable owner and a completion condition?
- [ ] Can any follow-up be folded into existing work?

## Delegation and gates

- [ ] Are product decisions with the Product Owner and technical decisions with the CTO?
- [ ] Does each delegation contain scope, exclusions, authority, evidence, and handoff target?
- [ ] Are Code Review and QA independent from implementation?
- [ ] Are optional privacy or documentation gates required for this change?

## Exceptions

- [ ] Is any role blocked by missing authority, information, access, or another deliverable?
- [ ] Can I resolve the dependency within existing authority?
- [ ] If escalation is needed, is the request precise and decision-ready?

## Closure

- [ ] Are gate results and residual risks recorded?
- [ ] Have completed or superseded tasks been closed?
- [ ] Is the next action obvious to the human owner?
